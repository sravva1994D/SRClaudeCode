# Patient Management System

A browser-based patient management system for one general physician in one clinic: patients, 15-minute appointments, consultations, printable prescriptions, visit history, CSV and PDF export, and single-doctor JWT login.

## Documentation

- `BRD/Doc_BRD.md`: business requirements
- `documents/brainstorm-review.md`: architecture decisions and the Decisions Log (Q1–Q22)
- `documents/implementation-plan.md`: phases, sprints and milestones
- `documents/worktree-plan.md`: branching and worktree rules
- `CLAUDE.md`: coding and workflow rules for this repository

## Stack

- Frontend: Angular 19 (standalone components), Angular Material
- Backend: ASP.NET Core Web API on .NET 10, Dapper, FluentValidation
- Database: SQL Server (LocalDB in development)

## Local setup

Setup and run commands will be added as Sprint 1 step 5 (local build and test scripts) is completed.

## Data

Development uses synthetic data only, generated by the seeding tool. Do not add real patient data to this repository.
